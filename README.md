# 수정구 아동급식카드 가맹점 지도

성남시 수정구의 아동급식카드 가맹점 184곳을 업종별로 나눠 지도와 목록으로 보여 주는 정적 웹 페이지입니다. (2022년 12월)

## 화면 구성

- **왼쪽 – 업종 메뉴:** 모두·한식·일식·중식·양식·아시안·분식·치킨·카페
- **오른쪽 위 – 가맹점 목록:** 가맹점명, 도로명주소, 위도·경도, 영업시간, 업종
- **오른쪽 아래 – 지도:** 업종별 색 마커를 표시하고, 마커를 누르면 가맹점명·주소·영업시간·업종을 보여 줍니다.

| 업종 | 가맹점 수 | 마커 색 |
|---|---:|---|
| 모두 | 184 | 업종별 색 |
| 한식 | 79 | 파랑 |
| 일식 | 14 | 초록 |
| 중식 | 14 | 빨강 |
| 양식 | 20 | 회색 |
| 아시안 | 2 | 베이지 |
| 분식 | 17 | 분홍 |
| 치킨 | 16 | 주황 |
| 카페 | 22 | 보라 |

## 사용 기술

- **지도:** Python folium으로 만든 Leaflet 지도(Leaflet 1.6, Leaflet.awesome-markers, CARTO 밝은 배경지도)
- **목록:** Microsoft Excel 시트를 웹 페이지로 저장(업종별 시트 9개)
- **화면 구성:** HTML iframe으로 메뉴·목록·지도를 한 화면에 배치

## 보는 방법

저장소를 내려받은 뒤 `수정구 아동급식카드 가맹점 지도.html`을 브라우저로 엽니다. 지도 라이브러리와 배경지도를 인터넷에서 불러오므로 인터넷 연결이 필요합니다.
